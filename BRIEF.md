# Build brief

## Decision

Build the narrowest honest thin workspace over the shared lead-generation
intelligence skill.

## Prove

1. Create, resume, duplicate, import, and export a project.
2. Capture the canonical ten-step, two-sided intake without forcing unknowns.
3. Register source metadata with actual detected type, explicit role, and
   template treatment.
4. Validate the minimum brief and expose research unknowns versus launch gates.
5. Run the canonical skill through a supported local adapter, or run an
   explicitly synthetic fixture with no silent fallback.
6. Review lane states, evidence IDs, findings, limitations, and representative
   Markdown outputs.
7. Show the full numbered Markdown/native-Google-Docs contract without faking
   publication or parity.

## Exclude

Signup, billing, teams, multi-tenancy, a marketplace, persistent server
database, autonomous actions, live campaigns, and native Google Docs creation.
