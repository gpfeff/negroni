# Product decision

The product is a single intake → research → deliverables page. It collects a
project name, partial freeform context, optional structured answers, URLs, and
attachments. The canonical shared skill performs complete client, market
awareness, B2B lead-buyer, B2C customer, competitor, and master-synthesis
research. A complete run creates exactly one Google Doc, one competitor Google
Sheet, and one substantively matching Markdown report.

The same run sends the verified competitor watchlist to the runner-side Meta Ads
Intelligence adapter. One idempotent job refreshes that isolated archive and the
same competitor Sheet nightly at 02:17 in the intake timezone. Monitoring is
not a fourth deliverable or a dashboard: the page shows only its active receipt
or exact blocker.

The former dashboard, saved projects, ten-step wizard, source/preflight/run/evidence/deliverables views, lane state, synthetic fixture, ten-document package, parity matrix, browser storage, and localhost companion are retired.

Missing inputs become visible unknowns, research questions, or limitations.
Missing secure execution becomes a blocker. Missing authorized competitor
collection makes the monitoring state blocked without hiding valid completed
research. Neither case becomes invented data.
