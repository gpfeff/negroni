# Product decision

The product is a single intake → research → deliverables page. It collects a project name, partial freeform context, optional structured answers, URLs, and attachments. The canonical shared skill performs the research. A complete run creates exactly one Google Doc, one competitor Google Sheet, and one substantively matching Markdown report.

The former dashboard, saved projects, ten-step wizard, source/preflight/run/evidence/deliverables views, lane state, synthetic fixture, ten-document package, parity matrix, browser storage, and localhost companion are retired.

Missing inputs become visible unknowns, research questions, or limitations. Missing secure execution becomes a blocker. Neither case becomes invented data.
