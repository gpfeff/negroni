# Design system

The interface is quiet, form-first, and constrained to an 880-pixel reading column. A restrained forest-green and warm-paper palette distinguishes action and status without dashboard chrome. Lora provides report-like headings; DM Sans provides readable form text.

The first viewport explains the workflow and begins intake. Optional fields remain on the page behind one native disclosure. Status is a single panel. Outputs are three large, accessible actions. There are no sidebars, ornamental diagrams, status-pill collections, or marketing-scale headline blocks.
