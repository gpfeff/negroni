# Design system

## Direction

Serious editorial intelligence workspace: paper, rules, manifests, and evidence
spines rather than a generic AI chat or ad-tech dashboard.

## Tokens

- Ink: `#142638`
- Buyer blue: `#2c568f`
- Consumer teal: `#0a777d`
- Evidence bridge: `#735b93`
- Gate amber: `#a65f25`
- Fog: `#eef3f5`
- Display: Archivo
- Body: Work Sans
- Utility/data: IBM Plex Mono

## Signature elements

- Buyer → evidence bridge → consumer band
- Vertical evidence spines with stable IDs
- Independent numbered lane cells
- Paper-like source and document contracts
- Gate callouts that remain visible without masquerading as run blockers

## Accessibility and responsiveness

The interface uses semantic headings, labels, tables, fieldsets, visible focus
states, reduced-motion treatment, high-contrast status text, desktop-first
workspace layout, horizontally scrollable contracts, and single-column mobile
reflow.

## Self-critique

The MVP favors traceability over density reduction. The ten-step intake is
necessarily long, so step navigation, answer-state controls, conditional
questions, and compact source handoff prevent it from becoming one giant form.
No decorative chart or completion percentage was added because neither would
represent research quality honestly.
